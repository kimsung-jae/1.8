# 보글사다리 삼치기80 BEST1 · 최근30 고정판 V1.7.30

기존 V1.7과 **별도 설치**되는 실험판입니다.

## 핵심 변경
- 현재 추천 계산의 학습 입력을 **최신 최대 30회로 고정**합니다.
- 31회 이전 결과는 저장/백업에는 남을 수 있지만 **현재 추천, META 규칙선택, Markov, Shape, KNN 계산에는 사용하지 않습니다.**
- 최근 30회 안에서만 8회/20회/30회 흐름을 비교합니다.
- 화면에는 기존 V1.7처럼 **최고 삼치기 1픽 한 세트만** 표시합니다.
- 80%는 실제 walk-forward 재현값 기준이며 임의로 올리지 않습니다.
- PASS 없이 매 회차 최고 삼치기 1픽을 출력합니다.
